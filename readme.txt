# MLab 数学实验室

这是一个面向中小学数学学习的可视化实验平台，通过拖拽的方式让学生在网页上进行简单的数学操作和实验。仓库中包含多个版本的 `MLab` HTML 文件以及更新记录。

## 文件说明
- `MLab_0.x.html`：不同版本的前端页面，直接在浏览器中打开即可体验。
- `CHANGELOG.txt`：详细的版本更新记录。

## 使用方式
1. 在本仓库中选择任意 `MLab_*.html` 文件。
2. 用浏览器打开文件，即可进入数学实验室界面。
3. 在欢迎页点击 **Start**，然后选择主题（例如“数与运算”“量与计量”“图形与几何”“概率与统计”）。
4. 在工具箱中拖拽需要的工具到工作台进行实验，可使用撤销/重做等功能。

## 更新历史
查看 `CHANGELOG.txt` 可以了解每个版本的改动与新增功能。
